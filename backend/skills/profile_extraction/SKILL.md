# Profile Extraction Skill

## 目标

从客户自然语言中抽取购车画像，将非结构化需求转换为推荐系统可使用的结构化字段。

## 输入

- 用户原始需求文本
- 页面表单中的补充画像

## 输出

- 预算上限
- 城市
- 家庭人数
- 通勤距离
- 家充条件
- 偏好车型
- 偏好能源类型
- 偏好品牌
- 关注点
- 意向阶段
- 用户点名车型

## 运行入口

```text
backend/app/services/skills.py
SkillRegistry.extract_profile()
```

## 业务价值

让 Agent 能理解“预算25万、三口之家、有家充、关注智驾”等真实销售表达，并将其传递给车型召回和推荐评分模块。

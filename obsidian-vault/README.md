# Obsidian Vault 使用说明

这个目录是 Soldier-Car-Smart-Recommendation 项目的 Obsidian 知识库。

## 如何打开

1. 在本地安装 Obsidian；
2. 打开 Obsidian；
3. 选择“打开本地库 / Open folder as vault”；
4. 选择项目中的 `obsidian-vault` 文件夹；
5. 从 `00-入口/Soldier-Car-知识库首页.md` 开始阅读。

## 约定

- 所有知识节点使用 Markdown；
- 使用 `[[双向链接]]` 建立关系；
- 使用 YAML Frontmatter 记录节点类型、模块和标签；
- 后续项目每次优化都要沉淀到这个 Vault。
